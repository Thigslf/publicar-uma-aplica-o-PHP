# publicar-uma-aplica-o-PHP

## Descrição
Este repositório contém instruções e scripts para publicar uma aplicação PHP.

## Passos para publicação

### Linha 22
Copia do Git para dentro da pasta do Apache.

```bash
cp -r /caminho/do/repositorio/* /var/www/html/
```

## Configuração
- Certifique-se de que a pasta do Apache tem permissões adequadas
- Configure o servidor Apache para apontar para a pasta correta
- Verifique se a aplicação PHP está funcionando corretamente

## Requisitos
- Git instalado
- Apache configurado
- PHP instalado e funcionando
